## Synopsis

```text
looper test-not [-h|--help] [--window-id <window-id>] <lhs> = <rhs>
looper test-not [-h|--help] [--window-id <window-id>] <lhs> ~= <rhs>
```

Negative condition evaluation utility

The subcommand works exactly the same as the `test` subcommand, except the result (exit code) is negated.
Please refer to the `test` subcomman documentation for more information.
