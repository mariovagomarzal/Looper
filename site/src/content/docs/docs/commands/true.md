## Synopsis

```text
looper true [-h|--help]
```

Return true value

The `true` utility returns with an exit code of zero.

The utility might return with a non-zero exit in case of errors (e.g. unexpected CLI arguments)

## Options

- `-h, --help`: Print help

## Exit codes

- `0`: No errors have occurred.
- `>0`: An error occurred. For instance, unexpected CLI arguments.
