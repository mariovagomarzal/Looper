== Synopsis
[verse]
looper [-h|--help] [-v|--version] <subcommand> [<subcommand-options>...] [<subcommand-arguments>...]

== Description

Looper is an i3-like tiling window manager for macOS

*looper* command line program is used to manipulate Looper and query its state.

See https://nikitabobko.github.io/AeroSpace/commands for available <subcommand> options

See each <subcommand> individual man page for <subcommand-options> and <subcommand-arguments>

== Options

-h, --help:: Print help
