= looper-move-node-to-workspace(1)
include::util/man-attributes.adoc[]
:manname: looper-move-node-to-workspace
// tag::purpose[]
:manpurpose: Move the focused window to the specified workspace
// end::purpose[]

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
looper move-node-to-workspace [-h|--help] [--focus-follows-window] [--wrap-around]
                                 [--stdin|--no-stdin] [--monitor <monitor>]
                                 (next|prev)
looper move-node-to-workspace [-h|--help] [--focus-follows-window] [--fail-if-noop]
                                 [--window-id <window-id>] [--monitor <monitor>] [--] <workspace-name>

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

`(next|prev)` is identical to `workspace (next|prev)`

// =========================================================== Options
include::./util/conditional-options-header.adoc[]

-h, --help:: Print help

--monitor <monitor>::
Move the window to a workspace of another monitor.
`<workspace-name>`, `next` and `prev` refer to the workspaces of that monitor, `next` and `prev` relative to its
visible workspace.
`<monitor>` possible values: `(left|down|up|right|next|prev|focused|pointer|wheel|<monitor-pattern>)`.
Directions, `next` and `prev` are relative to the monitor of the window.
`wheel` is the monitor that was under the mouse pointer when the wheel opened, and is only valid in wheel actions.
See `looper-focus-monitor` for monitor patterns.
--wrap-around:: Make it possible to jump between first and last workspaces using (next|prev)
--fail-if-noop:: Exit with non-zero code if move window to workspace it already belongs to

--focus-follows-window::
Make sure that the window in question receives focus after moving.
This flag is a shortcut for manually running `looper-workspace`/`looper-focus` after `move-node-to-workspace` successful execution.

--window-id <window-id>::
include::./util/window-id-flag-desc.adoc[]

--stdin::
Read the list of workspaces from stdin.
Incompatible with `--no-stdin`

--no-stdin::
Ignore the list of workspaces from stdin, even if provided.
Incompatible with `--stdin`

// =========================================================== Arguments
include::./util/conditional-arguments-header.adoc[]

(next|prev):: Move window to next or prev workspace
<workspace-name>:: Specifies workspace name where to move window to
