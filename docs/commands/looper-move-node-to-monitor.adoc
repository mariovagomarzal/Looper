include::./util/conditional-options-header.adoc[]

-h, --help:: Print help
--wrap-around:: Make it possible to wrap around the movement

--focus-follows-window::
Make sure that the window in question receives focus after moving.
This flag is a shortcut for manually running `looper-workspace`/`looper-focus` after `move-node-to-monitor` successful execution.

--fail-if-noop::
Exit with non-zero code if moving window to monitor it already belongs to
