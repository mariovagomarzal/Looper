// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
looper echo [-h|--help] [--stderr] [--window-id <window-id>] -- <string>...

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
Print `<string>...` arguments and *interpolation variables* to stdout.

You can use this command in combination with other commands to do various things:

* You can test shell operators
* You can pipe an explicit input to some other command (e.g. *looper-workspace*(1)) inside an *looper-eval*(1)
* You can print interpolation variables for the focused window (see *looper-list-windows*(1) for the list of interpolation variables)

// =========================================================== Options
include::./util/conditional-options-header.adoc[]

-h, --help:: Print help
--stderr:: Print to stderr instead of stdout
--window-id <window-id>::
include::./util/window-id-flag-desc.adoc[]

// =========================================================== Arguments
include::./util/conditional-arguments-header.adoc[]

<string>:: The argument to print.
Each `<string>` argument can contain *interpolation variables* similar to those in *looper-list-windows*(1).
You can specify multiple `<string>` arguments - each of them is printed on a separate line.

// =========================================================== Examples
include::util/conditional-examples-header.adoc[]

* Print the focused window title: `+looper echo -- %{window-title}+`
